Admin panel

Edit the receivers JSON below. Changes are saved to your browser (localStorage) and apply immediately for everyone viewing this site from this browser. To make changes permanent for all visitors, export and replace public/receivers.json in the project.
Each receiver has: slug (URL path), name, location, optional mc: {"x":0,"z":0} world coordinates for the dot on the world map, and a config with the same fields as before (tunerName, tuningMin/Max, stations[], presets[], etc.). Each station supports: freq, mount, pi, pty, af, ps, rt, tp, ta, ms, stereo, signal, station{}, optional flag, rdsDisabled.
mount can be either an Icecast mount name (served from radio.soupco.net:8443) OR a full http(s):// stream URL for any other server.
New global config options: audioDelayMs (stream latency, default 800), rdsMode ("rds" or "rbds" — different PTY tables), ptyOverrides ({"0":"None","10":"Pop"} to rename), dynamicPsMode ("groups" | "scroll" | "static", default "groups"), groupsHoldGroups (default 4), scrollStopStartMs, scrollStopEndMs, scrollSpeedMs.
New per-station options: logo (URL), volume (default 1.0; >1 drives the WaveShaper for an overmodulating-station feel), audibleBandwidth (overrides the global value for this station), eq (array of {freq, gain, q} parametric peaking bands), dynamicPsMode, scrollStopStartMs, scrollStopEndMs, scrollSpeedMs, groupsHoldGroups.
